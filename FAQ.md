# FAQ

## Is the Free Demo Audit really free?
Yes. It costs $0. Opening a request creates no payment obligation.

## What repositories can I submit?
For the public Free Demo Audit, submit only a public GitHub repository that you are comfortable discussing publicly.

## Do you need write access?
No. The free demo is read-only and uses repository-visible evidence.

## Can I submit a private repository?
Not through the public Free Demo Issue Form. Private work requires a separately agreed scope and explicit access authorization.

## What does the free demo include?
One public repository, one exact revision, and up to three high-leverage findings or observations.

## What happens after the demo?
Nothing automatically. If you want deeper work, a full audit or bounded remediation scope can be agreed separately.

## Are findings guaranteed vulnerabilities?
No. Findings are bounded engineering observations based on reviewed evidence and stated confidence. The service is not a penetration test or security guarantee.

## Why use an exact commit SHA?
Because branches move. Exact-revision binding makes it clear which source state the evidence and findings actually describe.

## Is this an automated scanner?
No claim is made that the service is a fully automated SaaS scanner. The founding service is evidence-first and can include manual/semi-automated expert review.

## What should never be posted in an issue?
Secrets, API keys, passwords, tokens, private source, confidential customer data, private repository URLs, or sensitive vulnerability details.
