# Maintainer Outreach Template

Use only after checking the upstream project's current contribution/security/communication guidance and only when an appropriate channel exists.

> Hi — I ran an independent public demonstration audit of this repository at an exact public commit to test an evidence-first GitHub audit method. This was not requested by the project and does not imply any partnership or endorsement. I published the bounded report here: <REPORT_LINK>.
>
> It focuses on what the repository's visible CI/evidence does and does not establish; it is not a vulnerability disclosure or a claim that the project is unsafe. No action is required — sharing only in case the evidence-scope observations are useful. If this channel is not appropriate, feel free to ignore/close this message and I will not follow up.

Rules:
- one initial message only unless maintainers respond;
- no security-sensitive detail in public outreach;
- no sales pressure or repeated follow-up;
- do not claim the upstream project is a customer, partner, or endorser;
- link to the exact public report rather than pasting a long audit into the upstream issue/discussion.
