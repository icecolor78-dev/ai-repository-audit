Evidence-first review of a public GitHub repository at one exact revision.

## What you get

A bounded audit is tied to an exact repository revision so findings do not silently drift with `main`. Evidence is separated from interpretation, unknowns remain explicit, and remediation is not called verified until it has actually been rechecked.

Typical review areas include:
- build, test and CI confidence;
- release-readiness gaps;
- architecture and maintainability risks;
- authentication/authorization boundaries visible in the reviewed source;
- evidence quality around AI-generated or AI-assisted changes;
- reproducibility and exact-revision discipline.

## How it works

1. Submit a Free Demo Audit request for a public repository.
2. Freeze the exact revision.
3. Review repository-visible evidence within the agreed scope.
4. Receive up to three prioritized observations/findings.
5. If useful, agree a paid full-audit or remediation scope separately.

This service is not a penetration test, certification, compliance attestation, legal opinion, or guarantee that software is secure or defect-free. Public demo findings are bounded to the evidence and exact revision reviewed.
